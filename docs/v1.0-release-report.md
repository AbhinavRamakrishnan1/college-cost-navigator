## Calculation corrections and preservation

Only the two explicitly approved RAP corrections changed federal calculation behavior:

- Preserve Decimal precision through annual-base calculation, divide by 12 without
  intermediate cent rounding, apply dependent reduction, spouse proration and the
  $10 floor in order, then round the final monthly payment to cents.
  The added $30,001.99 AGI regression returns **$75.00/month**.
- At RAP projection recalculation points, use projected borrower principal plus
  accrued interest. Spouse debt requires an explicit annual path or deliberately
  accepted constant assumption. Annual-path gaps fail closed. Current-payment
  calculation remains separate; no projection assumption is inferred from it.

New projection regressions cover declining borrower debt, changing spouse debt,
annual recalculation, accrued interest, missing assumptions, the $10 floor, and
unmarried/MFS invariance. The complete repayment suite passes, including existing
RAP, IBR thresholds, Tiered Standard boundaries, rate selection and forgiveness
crediting. No further calculation discrepancy was found. Existing expected values
remain unchanged; approved regression cases were added, not substituted.
SAI/Pell regressions remain unchanged, including Medicare HI **$7,367**, OASDI
**$24,837**, and the synthetic demo's **SAI 2,069 / Pell Scheduled Award estimate
$5,325**. Independent-student SAI remains unsupported.

## Storage, safety and privacy

IndexedDB schema remains **v4**; backup schema remains **v4**. Existing migration
tests pass and profiles survive upgrades. The optional spouse projection field is
backward-compatible and needs no indexed schema change. Old joint-filing scenarios
still calculate current payments but require an explicit assumption for projection.
No earlier released backup format needs migration; unsupported versions are rejected.

Round-trip tests cover all user stores, validation before writes, duplicate/orphan
rejection, deliberate confirmation, and transactional rollback after an injected
write failure. Delete-all empties profiles, schools, loan scenarios and projection
assumptions; static reference data remains intact. Browser tests export an actual
file, delete, restore and verify recovered records after reload.

Production-browser journeys inspect requests and console messages for financial
sentinels. Only same-origin GET reference/app resources are requested; no household,
SAI/Pell or loan data is transmitted. No analytics, trackers, remote fonts or external
Scorecard browser calls were added. Institution names are rendered as React text.
Credential-pattern scanning is evidence, not proof against every possible secret.
Local databases and exported backups are not encrypted.

Malformed profiles, saved schools, loans, unavailable/future IndexedDB and failed
snapshot loads receive safe recovery states rather than fabricated calculations.

## Accessibility and warnings

Desktop/mobile axe checks and built-app journeys pass, including keyboard skip
navigation, mobile Escape/focus restoration, narrow reflow and reduced motion.
No serious automated accessibility defect remains. Real NVDA/VoiceOver testing,
actual 200%/400% browser zoom, forced colors and manual reading/focus order have
**not** been performed. The detailed manual checklist is documented in
[production operations](production-operations.md); do not interpret automated
passes as screen-reader certification. Any serious defect found there blocks release.

Remaining warnings/limitations: Playwright emits the harmless `NO_COLOR` versus
`FORCE_COLOR` environment warning; Git emits LF-to-CRLF checkout notices
(`git diff --check` exits 0 with no whitespace errors); manual checks and hosted preview verification
remain unexecuted; field-of-study data is unavailable; the catalog is a single lazy
download; projections depend on user assumptions and forgiveness is not guaranteed.
No other unresolved calculation discrepancy or release-critical automated failure
was found. Independent Formula B/C and all other excluded v1.1 features remain out
of scope.
