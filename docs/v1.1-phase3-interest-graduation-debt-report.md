# v1.1 Phase 3 interest and graduation-debt foundation

Status date: September 21, 2026  
Scope: pure in-school interest and projected new-debt-at-graduation calculations only

## Interest model

The engine consumes the existing dated loan ledger as its sole principal, ownership, loan-type, fee, net-proceeds, and disbursement source. For interest-bearing loans, each gross-principal disbursement is calculated independently using:

`principal × annual rate × elapsed days / 365.25`

Decimal arithmetic is preserved through the sum of all disbursement-level interest for a loan. The engine does not round daily or compound. Final loan-level accrued interest is rounded once to integer cents using half-up monetary rounding. It does not change global Decimal configuration.

## Day-count convention

Date-only values are parsed at UTC midnight. Elapsed days exclude the disbursement date and include the graduation/planning-end date. A same-day interval therefore has zero elapsed days. Leap days are naturally included in the UTC day difference; the planning denominator remains 365.25.

An explicit graduation date is required. It is never inferred from the current date, a four-year horizon, or Scorecard completion data. Malformed dates and graduation before a disbursement fail closed while preserving safe principal information where validation permits.

## Rate selection and provenance

Known rates come from the existing fixed-rate cohort reference selected from each loan's first disbursement. Later installments retain that loan-level cohort even if their dates fall in another rate window. The ledger boundary now maps the canonical policy fields to percentage points explicitly: 2026–27 undergraduate Direct loans resolve to 6.52%, and Parent PLUS resolves to 9.07%.

Future cohorts are not guessed. Each affected loan requires a distinct known, assumed, or unknown planning-rate value with provenance. An unknown rate leaves principal visible but makes the affected interest and aggregate informational debt totals incomplete.

## Subsidized treatment

For explicitly confirmed qualifying in-school enrollment, borrower interest on Direct Subsidized principal is zero through the planning-end date. Principal is unchanged. Unresolved enrollment facts make the affected loan incomplete; unsupported enrollment treatment returns an unsupported result. The engine does not extend the subsidy beyond this stated period.

## Unsubsidized and Parent PLUS treatment

Direct Unsubsidized and Parent PLUS interest accrues from each actual ledger disbursement date. Parent ownership remains separate from student ownership. The supported planning path explicitly assumes no voluntary in-school payments; a plan requiring payment allocation is unsupported. Parent PLUS is not given the student's grace period, and this engine stops at the graduation/planning-end date.

## Graduation-debt snapshot

Every loan snapshot retains borrower ID and role, student beneficiary, loan type, gross principal, rate and provenance, accrued interest, and an informational principal-plus-interest amount. Principal and interest remain separate:

- `principalCents`
- `accruedInterestCents`
- `informationalPrincipalPlusInterestCents`

The informational sum is not called a capitalized balance. No capitalization event is applied merely because graduation occurs.

## Borrower-separated totals

Student totals separately expose subsidized principal, unsubsidized principal, total student principal, accrued interest, and informational debt from the plan. Each parent receives an independent Parent PLUS summary. An all-parent summary is separate from the student summary. The optional cross-borrower view is explicitly named `combinedHouseholdAssociatedBorrowing`, not student debt.

The scope label is `Projected new debt from this plan at graduation`. Existing debt is not integrated and the result is not represented as total student debt at graduation.

## Result states

The engine returns explicit `complete`, `requires_assumption`, `incomplete`, or `unsupported` states. Safe loan principal remains visible when a future rate or supported interest treatment is unresolved. No missing rate, enrollment fact, or payment treatment is converted to zero.
